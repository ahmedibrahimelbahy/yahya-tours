Scope of Work

What We're Building

A complete, professional web presence — every page designed to turn visitors into bookings.

Hero Page

Full-screen Egypt visual, a powerful headline, and a "Book Now" button that captures attention from the first second.

Featured Tours

Showcase 3–6 signature tours as visual cards — cover photo, title, duration, price, and a "View Details" button.

Tour Detail Page

Dedicated page per tour: full itinerary, what's included/excluded, photo gallery, and an embedded booking form.

Online Booking Form

Name, email, WhatsApp, tour, date, group size — saved to the database and emailed to Yahya automatically on every submission.

About Yahya

Your story, experience, and vision — the trust-builder that turns curious visitors into confident, paying customers.

Photo Gallery

A visual grid of Egypt's landmarks and tour experiences — the most powerful sales tool there is.

Testimonials

Star-rated reviews from past tourists — the social proof that converts hesitant browsers into booked travelers.

FAQ

Visa info, cancellations, what to pack — answers that remove booking objections automatically, 24/7.

Contact

WhatsApp button, email, social links, contact form — every channel a tourist might prefer to reach you on.

Functionality

Key Features

Built for two audiences — tourists get a seamless booking experience, you get total control.

For Tourists

  • Browse all tours with full photos, itineraries, and transparent pricing
  • Book directly from the website — no need to DM or call first
  • Receive an automatic email confirmation the moment they submit
  • Read the complete itinerary and inclusions before committing
  • Reach you instantly via a floating WhatsApp button on every page

For You (Admin)

  • Instant email alert every time a booking is submitted
  • Simple admin dashboard to view and manage all reservations
  • Add, edit, or remove tours and update pricing — no developer needed
  • See which tours get the most views and bookings via analytics
  • All bookings stored securely — name, contact, date, group size, notes

Technology

Tech Stack

Every tool chosen for a reason — modern, scalable, and built to grow with your business.

Next.js 14
Frontend Framework

Fast, SEO-friendly React framework. Every tour gets its own Google-indexable URL — tourists searching for Egypt tours will find you.

Tailwind CSS
Styling System

Utility-first CSS that builds consistent, professional designs rapidly with a pixel-perfect result on every screen size.

Supabase
Database & Backend

Stores all bookings and tour content securely. Also powers the admin dashboard where you manage everything — no coding needed.

Resend
Email Delivery

Beautiful confirmation emails to tourists + instant booking alerts to your inbox — automatically on every submission, zero effort from you.

Cloudinary
Image Hosting

Globally optimized image delivery. Egypt's stunning photos load instantly on every device and connection speed — no tourist waits.

Vercel
Deployment & Hosting

Instant global deployment with automatic updates. No server to maintain, no downtime — the site just works, always.

Built to scale — online payments, Arabic, or a blog can be added later without rebuilding from scratch.
